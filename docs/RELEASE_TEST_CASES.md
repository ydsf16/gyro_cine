# GyroCine 发版测试用例库

每次测试**最终候选构建**，记录 App 构建号、Git commit、机型/iOS、存储位置、剩余空间和结果。历史版本的 PASS 不能直接沿用。只清理本轮明确标记的测试素材；失败原片和日志先保留。

## 一、当前设计（一页速览）

| 模块 | 当前实现与发版时要守住的边界 |
| --- | --- |
| 视频 | H.265/H.265 HQ 主要走 `AVCaptureMovieFileOutput`；iOS 27 兼容设备上的 ProRes RAW/RAW HQ 使用 `AVCaptureVideoDataOutput + AVAssetWriter`。RAW Writer 将正常连续帧规整到目标时间轴，真实丢帧保留缺口和原始采集时间映射。 |
| 传感器与封装 | Core Motion 先于视频采集、晚于视频结束；逐帧相机内参 K 与曝光信息、IMU 在录后封入单个 MOV，视频不重新编码。默认 Gyroflow 兼容输出，另有 Gyroflow Nightly 选项。缺 K 的格式不能宣称可用于增稳；素材显示红色 `!IMU`。 |
| 存储 | H.265 可存 App 内部文件；RAW 使用设备支持的专用视频存储或 SSD。内录素材与诊断分别在 `Media`/`Log`，SSD 使用系统目录 `DCIM/100APPLE/IMG_####.mov`。空间、持续写入和缓冲异常须安全停录并保留原片。 |
| 控制与预览 | 物理镜头、编码/尺寸/FPS、A-Max/手动曝光、白平衡、对焦、LUT、辅助线、场记；设置跨启动保留。LUT 只改变预览，录制文件不烘焙。录制方向在开始时由重力确定。 |
| 商业化 | H.265 等功能免费；RAW/RAW HQ 每段免费 2 分钟，Pro 一次买断解锁长录。TestFlight 沙盒豁免与正式包应分别验收。 |

## 二、快速发版（约 30–60 分钟/代表机型）

适用：文案、UI、小范围修复后的候选版。执行全部 Q 项；设备没有 RAW/专用存储时记录 `N/A`，不能把未测项写成通过。

| ID | 操作 | 通过标准 |
| --- | --- | --- |
| Q1 启动与配置 | 覆盖安装候选版，冷启动；查看权限、预览、存储/IMU 状态；设置一组规格，退出重开。 | 无卡屏/旧错误弹窗；配置保留；可回到 Ready。 |
| Q2 H.265 基础片 | 1×、优先 4K60（不支持则用最高常用规格）、内部文件录 15 秒，停止后立刻再录 5 秒。 | 两片均保存、播放、带音频和有效 IMU/K；保存后可再次录制。 |
| Q3 RAW 基础片 | 兼容机选 RAW 4K30，在专用存储或 SSD 录 15 秒；切 RAW HQ 再录 5 秒。 | MOV 可完整解码，音频及内嵌 IMU/K 存在；无异常帧间隔；Media 标绿 IMU。无设备/空间则 `N/A`。 |
| Q4 镜头/参数 | 1×→0.5×→1×（有 4× 再测 4×→1×）；近远移动看 AF，检查实际 FPS；改手动快门/ISO 后切镜头。 | 不黑屏/闪退，AF 可持续重新对焦；手动值保留或按设备合法范围调整；新片规格与界面一致。 |
| Q5 素材与方向 | 打开本轮片播放、分享入口；横拍和竖拍各查看一片。 | 播放不闪；时长、IMU 标记、方向正确；只删除本轮明确标记的测试片。 |
| Q6 后期抽查 | 将一段带 IMU 的本轮 MOV 导入 Gyroflow，短片增稳预览并导出。 | 视频、运动数据和镜头信息被识别；导出方向正确、无明显末尾卡顿或反向增稳。 |
| Q7 发布包 | 用将要分发的 Release/TestFlight 包复查版本、图标、语言、Pro 页面和 RAW 免费时长提示。 | 构建号正确；正式包不被沙盒豁免解锁；无购买/恢复购买阻断。购买交易可用沙盒单独回归。 |

**快速发版阻断项：** 崩溃、无法再次录制、支持的配置生成不可解码 MOV、明显持续丢帧、音频/应有 IMU 缺失却显示成功、方向错误、RAW 付费限制失效。文件“已保存”提示本身不算通过。

## 三、详细发版（约半天/代表设备；高码率复制另计）

适用：录制链路、IMU/时间轴、存储、相机格式或付费逻辑变更；正式上架前至少做一次。先运行快速发版，再运行 D 项。

| ID | 用例 | 最小覆盖与重点 |
| --- | --- | --- |
| D1 规格矩阵 | 每个可用镜头选一项最高常用规格；1×覆盖 H.265/HQ、RAW/HQ 的 4K/Open Gate 与 30/60fps；120fps 只测设备实际提供项。核对菜单仅列可用组合，切换后编码/尺寸/FPS 与 MOV 一致；不支持记 `N/A`。 |
| D2 长录与性能 | 内部 H.265 4K60、RAW 专用存储或 SSD 各录 5 分钟；高码率 HQ 在 SSD 测速及空间足够时再录。检查逐帧时间、真实丢帧、热状态、缓冲峰值、停止及 IMU 封装耗时、连续再录。 |
| D3 时间同步/增稳 | 1× 和另一镜头各录一段有纹理、轻微左右摆动的片；短曝光与长曝光各一段。检查 K/IMU 覆盖视频首尾、原始采集时间与呈现 PTS 映射；Gyroflow 自动同步并导出，观察起末段和抖动。 |
| D4 存储异常 | 内部/专用/SSD 切换、容量回收、低空间提前停录、SSD 测速和风险提示；有 SSD 时由现场人员做一次短录中拔插，再不重启重录。中断片明确标记，原片/日志保留；恢复片须重新验收。 |
| D5 控制与界面 | A-Max/角度/FPS 联动、手动快门/ISO 合法钳制、EV、RAW 白平衡锁定、H.265 AL/A/M、点按/锁定/连续 AF、LUT 开关、重力水平线、音量键、中文/英文、设置跨启动保留。对照实际设备读数和输出片，不能只看按钮。 |
| D6 素材与封装 | Media 播放、缩略图、IMU 红绿标、分享/保存相册/多选删除；BMC/简洁文件名、场记元数据；横竖屏在手机/Gyroflow/导出中一致。检查单 MOV 中视频、AAC、遥测和 K 轨；LUT 开关前后不改变录制链路。 |
| D7 Pro 与恢复 | RAW 免费片达到 120 秒正常停止并保存；购买、恢复、退款状态和正式包限制；后台/锁屏中断后恢复补写；一次可控封装失败后无重复旧错误、可继续录制。 |

## 四、每片统一验收与记录

记录一行：`ID｜版本/设备｜镜头-编码-尺寸-FPS-存储｜时长/帧数｜最大 PTS 间隔/估计缺帧｜音频｜IMU/K｜完整解码｜Gyroflow｜结果与证据路径`。结果仅用 `PASS / FAIL / N/A / BLOCKED`。

录制片的最低门槛：MOV 能**完整解码**，时长和实际 FPS 合理，视频 PTS 单调；按所选 FPS 统计超过 `1.5 帧周期` 的间隔和估计缺帧；AAC 可听；宣称 Gyroflow 兼容时 IMU、K 覆盖实际视频区间。RAW 要同时看原始采集时间映射和规整后的呈现时间轴。异常必须保留 MOV、事件日志及设备热/存储状态，再判定原因。

可复用 `Tests/`、`UITests/IMURecordingUITests.swift`、`tools/analyze_capture_cadence.py`、`tools/validate_intrinsics.py` 和 `tools/compare_mov_timing.py`。完整操作矩阵及历史结果见 [录制稳定性复测计划](RELEASE_RECORDING_STABILITY_PLAN.md) 与 [2026-10-18 实测记录](RELEASE_RECORDING_STABILITY_2026-10-18.md)。模拟器、UI 自动点击和历史实测均不替代当前候选包的真机 MOV 验收。
