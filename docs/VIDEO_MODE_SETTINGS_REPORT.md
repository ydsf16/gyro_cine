# 分辨率与帧率设置

## 实现

- 设置提供独立的分辨率和帧率选项，枚举当前物理镜头、当前编码对应的设备格式和帧率范围。
- HEVC 提供设备支持的1920×1080、3840×2160；首次默认1080p30。
- RAW只提供原生Bayer尺寸，不缩放、不伪造1080p能力。优先保留用户规格；不支持时选择可用的最小30fps规格，并显示具体尺寸。
- 帧率候选24、25、30、60fps，仅显示设备支持值。切换分辨率、镜头或编码时重新匹配formatIndex；不支持的曝光上限回到自动。
- 采集使用选定的帧时长、编码尺寸；HEVC码率随像素数和帧率缩放，1080p30目标10Mbps，4K30目标40Mbps。RAW继续采用Apple推荐编码参数。
- diagnostics增加可选requestedFrameRate字段；旧素材按30fps解析。Gyroflow检查采用请求帧率，镜头配置标注实际尺寸和测得帧率。
