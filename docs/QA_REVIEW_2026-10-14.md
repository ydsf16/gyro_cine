## 尚未覆盖与保留问题

- **外部 SSD 尚未接入当前重建录制核心**：菜单明确标为待接入。当前设备不支持 ProRes RAW，无法验收 RAW/RAW HQ、SSD 热拔插及 4× 长焦切换。
- 物理近远移动、四方向实际手持拍摄、摇动相机的防抖效果，需要可控场景；自动化点击不能替代光学验收。
- 当前整段 IMU/K/metadata packet 在封装时读入内存，内存消耗随时长增长。一分钟测试不能证明数小时录像可靠，后续应改成流式封装并测长录制。
- Sony RTMD 标准兼容字段主要表达等效焦距，完整逐帧 K 的精度验收以 Proto 和内嵌诊断信息为准；畸变系数/滚动快门读出时间尚未标定。
- 曝光中心/光学时间偏差保持原方案，按此前决定暂不调整。没有声称已做光学校准。
- 本轮未通过修改权限、填满用户手机或强制重启来测试破坏性场景。存储不足/损坏输入由逻辑用例覆盖；用户主动锁屏的真实 File Protection 行为与转后台仍有区别。
- 遗留同步 AVAsset API 有弃用警告；大量素材时的扫描/缩略图性能还需要大素材库压测。
