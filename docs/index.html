录制与存储

  • H.265 可录制到内部文件；ProRes RAW / RAW HQ 需要兼容机型、系统和专用视频存储或外接 SSD。
  • 专用视频存储需先在系统设置中分配容量；SSD 需获得访问授权，并具备足够的持续写入速度。
  • 素材在 App 的「素材」中查看、分享或保存到相册；内部文件可通过 iOS「文件」App 访问。

免费与 Pro

H.265 及其他功能免费。ProRes RAW / RAW HQ 每段可免费录制 2 分钟。一次性购买 GyroCine Pro 可解除这项时长限制；实际时长仍受容量、温度和设备限制。价格以 App 内购买页面为准。更换设备后可在「设置 → GyroCine Pro → 恢复购买」恢复同一 Apple 账户的购买。

Gyroflow 与监看

支持的录制格式可在 MOV 内嵌运动数据和相机参数。请使用与所选输出模式兼容的 Gyroflow 版本。监看 LUT 只影响预览，不写入视频画面。增稳在后期软件中完成；相机内参不等于完整镜头畸变校准。

需要帮助？

请在 GitHub Issues 提交问题，注明机型、iOS 和 App 版本、编码、分辨率、帧率、存储方式及复现步骤。请勿公开密码、购买凭证、私人素材或敏感日志。退款请通过 Apple 申请。

Support

GyroCine records video together with motion data for a Gyroflow post-production workflow.

Recording and storage

H.265 supports internal files. ProRes RAW and RAW HQ require compatible hardware, iOS, and Pro Video Storage or an external SSD. Allocate Pro Video Storage in system settings before use. External SSD recording requires access permission and sufficient sustained write speed. Open Media to preview, share, or save clips to Photos; internal files are accessible in the iOS Files app.

Free and Pro

H.265 and all other features are free. Each RAW / RAW HQ clip is free for up to 2 minutes. GyroCine Pro is a one-time purchase removing this limit, subject to hardware, temperature and storage constraints. The purchase sheet shows your local price. Restore using the same Apple Account in Settings → GyroCine Pro → Restore Purchases.

Gyroflow and preview

Supported formats embed motion data and camera parameters in MOV files. Use a Gyroflow version compatible with the selected output mode. Monitoring LUTs affect preview only. Stabilization is performed in post-production; camera intrinsics are not a complete lens distortion calibration.

Contact

Use GitHub Issues for support. Include device, iOS and app versions, codec, dimensions, frame rate, storage type and reproduction steps. Do not post credentials, receipts, private footage or sensitive logs. Request refunds through Apple.
